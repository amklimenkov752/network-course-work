# Курсовая работа по компьютерным сетям

- Студент: Клименков Артем
- Группа: ИУ7-71Б
- Тема: HTTP-сервер статических файлов
- Вариант: `select + thread pool`

## Сборка и запуск

```sh
make
./static-server --root DIR [--host IPv4] [--port 1..65535] [--threads 1..32] [--log FILE]
```

Параметр `--root DIR` обязателен и задаёт каталог статических файлов.

Параметры по умолчанию:

- адрес: `127.0.0.1`;
- порт: `8080`;
- количество worker-потоков: `4`;
- файл журнала: `logs/server.log`.

Пример запуска с каталогом `public`:

```sh
./static-server --root public
```
